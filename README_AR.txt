متجر DOCTOR WATCHES - دليل التشغيل

1) افتح https://github.com وأنشئ حسابًا مجانيًا.
2) أنشئ Repository جديدًا باسم doctor-watches واجعله Public.
3) ارفع ملف index.html الموجود في هذا المجلد إلى جذر المستودع (Add file > Upload files).
4) افتح Settings > Pages.
5) في Build and deployment اختر Deploy from a branch، ثم main و / (root)، واضغط Save.
6) انتظر اكتمال النشر. سيظهر رابط شبيه بـ https://USERNAME.github.io/doctor-watches/

تعديل المنتجات:
- افتح index.html في محرر نصوص.
- ابحث عن const products = [ وعدّل أسماء المنتجات والأسعار وروابط الصور والوصف.
- الأسعار والصور الحالية أمثلة تجريبية وليست عروضًا حقيقية.
- رقم واتساب مضبوط على 201070324860. لتغييره عدّل WHATSAPP_NUMBER بصيغة دولية بدون علامة +.

ملاحظات:
- الاستضافة والرابط عبر GitHub Pages مجانيان للخطة العامة والمستودع العام.
- المتجر واجهة أمامية ولا يحتوي على لوحة إدارة أو قاعدة بيانات أو تتبع مخزون/طلبات مركزي.
- الطلبات تُرسل برسالة واتساب، ويجب متابعة المحادثة يدويًا.
- لا توجد بوابة دفع؛ طريقة الدفع المعروضة هي الدفع عند الاستلام.
- الصور التجريبية مستضافة خارجيًا وقد تحتاج استبدالها بصور منتجاتك.
